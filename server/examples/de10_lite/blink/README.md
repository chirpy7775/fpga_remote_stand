# Blink

`blink.svf` — настоящая прошивка для DE10-Lite с мигающим светодиодом. Это
исходный `DemoBlink.svf`, перенесённый сюда без изменения содержимого.

Файл можно отправить через веб-интерфейс без сценария `.txt`. Исходный
Quartus-проект этого примера в исходном репозитории отсутствовал, поэтому здесь
сохранена только готовая прошивка.
