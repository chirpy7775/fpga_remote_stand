# Агент FPGA-стенда

Обычная установка на Raspberry Pi:

```bash
./install.sh --mode hardware --server http://<сервер>:8000 --token <токен>
```

Если `server/` лежит рядом и уже установлен, адрес и токен подхватятся
автоматически: `./install.sh --mode hardware`.

Для запуска без реального железа используйте `--mode simulation`. После
установки режим меняется одной строкой `MODE=` в `.env`. Там же находятся
камера, gpiochip, список BCM-пинов, OpenOCD, таймауты и рабочий каталог.

В hardware-режиме установщик ставит `openocd`, `ffmpeg` и `python3-lgpio`, а
также добавляет пользователя сервиса в группы `gpio`, `video` и `plugdev`.

Линии GPIO захватываются только на время задачи или сессии. После завершения
они переводятся во входы без подтяжки, чтобы Raspberry Pi не спорила с FPGA.
